Feliz cumpleaños — Página "Para Ti"

Descripción
---
Pequeña página web para celebrar un cumpleaños. Contiene:
- Pantalla principal: mensaje de bienvenida.
- Nuestra historia: sección con fotos y fechas (pon tus fotos en la carpeta `images/`).
- Regalo interactivo: mini-juego ligero (captura corazones).
- Cartas de amor: cartas con modal para leer mensajes.

Cómo usar
---
1. Copia tus fotos a `images/` (crea la carpeta si no existe). Usa los nombres `photo1.jpg`, `photo2.jpg`, etc., o cambia las rutas en `index.html`.
2. Abre `index.html` en tu navegador. En PowerShell puedes ejecutar:

```powershell
Start-Process "d:\SEMESTRE II-2025\ParaTi\index.html"
```

3. Haz clic en "Abrir regalo" y luego "Empezar juego" para probar el mini-juego.

Siguientes pasos sugeridos
---
- Reemplazar las imágenes por tus fotos reales.
- Mejorar el mini-juego (niveles, temporizador visible, puntuación almacenada).
- Añadir formulario para enviar nuevas cartas dinámicamente.

Si quieres, sigo y te ayudo a integrar el juego completo y a añadir un formulario de cartas con almacenamiento local o backend. ¡Dime con qué te gustaría continuar! :)
